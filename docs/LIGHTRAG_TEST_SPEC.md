# LightRAG V1 验收规格

## 第一关：真实依赖合同

在独立 Python 环境和临时 PostgreSQL + pgvector 容器上验证；模型和 Embedding
替身只替换外部付费调用，索引、数据库、SDK、图操作使用真实实现。

1. 两个 workspace 使用同名实体、同名文件和相同文本，查询/图/状态互不泄漏。
2. 标准 ainsert 接受外部分配的资料版本 ID；aquery_data 返回的 chunk_id 可通过
   text_chunks.full_doc_id 精确映射；同库重复内容行为被明确处理。
3. 两份资料共同支持一个图对象；删除一份后只撤销其来源，不错误清除另一份证据。
4. 实体重命名/合并、关系删除通过真实 SDK 操作生效；重新索引后的变化可由应用
   纠错日志按顺序幂等恢复，不依赖上游天然保留人工修改。
5. 中途失败可被检测，重试/重建得到一致的图、向量和来源；未通过不能宣传产品可用。

## 应用与恢复

- 越权 owner/KB/workspace、伪造 chunk/source/web snapshot 必须拒绝。
- mutation epoch 在写入前持久化；更新与 dirty 状态不可查询；失败后旧会话即使
  revision 未变也不能发布答案。
- 幂等重放无重复导入/纠错；revision 冲突 409；名称碰撞要求明确合并；别名无环。
- 删除已消失关系幂等，失去来源的规则休眠，重建不会创建无来源节点。
- DB 故障/服务重启/任务中断可恢复，不把部分写入标为 ready。
- 旧 Autonomous 快照 v1/v2/v3 和浏览器记录可迁移；原工具契约一致仍可恢复，真实
  契约变更仍拒绝。新会话权限不得因恢复扩大。
- 正文快照不塞入有限会话 payload；过期、已删除和版本变化有稳定错误语义。
- 抓取测试覆盖 localhost/IPv4/IPv6/保留地址、DNS 重绑定、重定向到内网、凭据 URL、
  超时/超限/脚本/提示注入。查询开关关闭时不能调用任何联网旁路。
- 网页引用展示实际来源；主动收录保存同一哈希，过期返回 410。

## UI 与回归

- 桌面及 390px：两库创建、上传、局部图谱、来源、重命名/合并/删除、跨文档问答、
  联网、保存网页、删除资料、失败重试、刷新后恢复。
- 超过图谱显示上限有截断说明和可访问列表；危险 URL/HTML 不直接渲染。
- 原文档管理、学习路径、Quiz、自适应辅导、历史引用和会话保持回归通过。
- Python ruff、pytest 分支覆盖率 >= 75%；前端 lint/build/Playwright；Compose 配置、
  健康、内部端口隔离和镜像启动验证。
- 同时备份恢复新数据库、材料卷和配置后，引用和纠错依然有效。

## 质量评测

冻结医学/机器学习测试资料、单文档/跨文档/无答案问题与模型配置；匹配语料范围
比较当前混合检索与 LightRAG。保留逐题证据、成本、延迟及失败原因，允许零提升。
不改写现有冻结报告，不把替身测试称为真实模型效果。
